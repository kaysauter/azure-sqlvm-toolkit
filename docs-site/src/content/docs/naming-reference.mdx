---
title: Naming Reference
description: Current generated names.
---

The current script uses deterministic names based on `resourceGroup.name`.

| Resource | Name shape |
| --- | --- |
| VNet | `<resourceGroup.name>-vnet` |
| VM subnet | `<resourceGroup.name>-subnet` |
| NSG | `<resourceGroup.name>-nsg` |
| NIC | `<resourceGroup.name>-nic` |
| VM | `<resourceGroup.name>-vm` |
| Bastion | `<resourceGroup.name>-bastion` |
| Bastion public IP | `<resourceGroup.name>-bastion-pip` |
| VM public IP | `<resourceGroup.name>-pip` when enabled |

Configured directly:

- `keyVault.name`
- `storage.accountName`
- `storage.fileShareName`
- `storage.resourceGroup`

Generated-name override support is a roadmap item.
