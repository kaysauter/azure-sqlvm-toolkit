This page is a convenience notice, not legal advice. Always review upstream source, license, support, and security posture before using third-party tools or sample data.

## Used Today

| Project / Publisher | How The Current Toolkit Uses It | Source Links |
| --- | --- | --- |
| Azure PowerShell / Az modules | Creates Azure resources and runs VM commands. | [Az PowerShell docs](https://learn.microsoft.com/powershell/azure/) |
| PowerShell project and contributors | Runs the toolkit and guest setup scripts. | [PowerShell repo](https://github.com/PowerShell/PowerShell), [PowerShell docs](https://learn.microsoft.com/powershell/) |
| powershell-yaml | Parses `config.yaml`. | [powershell-yaml](https://github.com/cloudbase/powershell-yaml) |
| Chocolatey Software and Chocolatey community | Sample guest setup downloads Chocolatey's bootstrap script and installs VM tools. | [Chocolatey docs](https://docs.chocolatey.org/en-us/getting-started/), [Chocolatey packages](https://community.chocolatey.org/packages) |
| dbatools community | Guest setup installs `dbatools`; `restore-databases.ps1` uses it for `.bak` restores. | [dbatools](https://dbatools.io/), [dbatools GitHub](https://github.com/dataplat/dbatools) |
| Tabular Editor | Installed by the sample guest setup through Chocolatey. | [Tabular Editor](https://tabulareditor.com/) |

Before enabling any optional download or installer in future code, review licensing, storage requirements, data sensitivity, and supply-chain risk.
