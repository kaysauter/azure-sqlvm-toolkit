## Attribution Rules

AzSQLVMKit does not relicense upstream work. The toolkit only automates installation or restoration from public sources.

Before enabling optional third-party content, check:

- upstream license and attribution requirements
- whether the source allows redistribution, commercial use, or modification
- support expectations and release notes
- storage requirements and Azure runtime cost
- checksum, signature, or mirroring options for repeatable deployments
- package-specific notices when a package manager installs software on your behalf

For production-grade or classroom-grade reproducibility, prefer an approved internal artifact mirror with pinned versions and documented checksums.
