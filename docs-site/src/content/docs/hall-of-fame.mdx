AzSQLVMKit is a small project built on a large SQL Server, Azure, and PowerShell community.

## Current Dependencies

**Chrissy LeMaire and the dbatools community** created and maintain one of the most useful SQL Server PowerShell ecosystems. The current restore helper uses dbatools to restore `.bak` files inside the VM.

**Chocolatey Software and package maintainers** make the sample guest setup short enough for labs by providing package installation for common tools.

**PowerShell contributors** make the scripting model possible across local setup, Azure automation, and guest execution.

**Microsoft product and documentation teams** maintain Azure, SQL Server, SQL Server on Azure VMs, PowerShell docs, and the platform references this toolkit depends on.

## Roadmap And Manual Lab Inspiration

These people and projects are not automated by the tracked script today, but they are important to the lab scenarios this toolkit may support later:

- Brent Ozar and contributors for the First Responder Kit.
- Ola Hallengren and contributors for the SQL Server Maintenance Solution.
- Alberto Ferrari, Marco Russo, and SQLBI contributors for Contoso sample data and BI education.
- Daniel Hutmacher for SQL Server community resources and sample data.
- The Microsoft SQL Server samples team for AdventureWorks and WideWorldImporters.

Future automation around these sources should stay opt-in and include licensing, attribution, size, and operational warnings.
