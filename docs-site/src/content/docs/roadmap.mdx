## Near Term

- Keep the module command and compatibility script stable.
- Expand validation coverage as the config surface grows.
- Add more mocked and live integration coverage for Azure resource reconciliation.
- Improve idempotency and drift reporting.
- Reduce guest setup supply-chain risk with pinned or mirrored artifacts.

## Module Hardening

- Move Azure create/reuse internals behind smaller `Ensure-*` functions.
- Add full Azure-aware `SupportsShouldProcess`, `-WhatIf`, and `-Confirm` behavior for each mutating operation.
- Add generated-name overrides.
- Extend Pester and CI coverage for future public module commands.

## Feature Ideas

- VM size and SQL image discovery.
- Local Markdown cost estimates.
- Allowlisted sample database restore.
- Config-driven local backup upload with manifest generation.
- Optional First Responder Kit installer.
- Optional Ola Hallengren Maintenance Solution installer.
