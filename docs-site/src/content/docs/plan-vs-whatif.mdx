## Current `-Plan`

`-Plan` is available today:

```powershell
New-AzureSqlVmToolkitDeployment -ConfigFile .\config.local.yaml -SecurityAssessmentAdvice -Plan
```

It does not call Azure. It validates config and prints the intended deployment shape.

## Current `-WhatIf`

The public module command supports PowerShell `-WhatIf` and maps it to the safe no-Azure plan path:

```powershell
New-AzureSqlVmToolkitDeployment -ConfigFile .\config.local.yaml -WhatIf
```

This validates config, prints the local deployment plan, and emits PowerShell WhatIf messaging. It does not perform Azure-aware drift checks yet.

## Roadmap

The remaining work is full Azure-aware `SupportsShouldProcess` coverage across every mutating create/update operation.
