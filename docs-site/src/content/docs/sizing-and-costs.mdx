The tracked script does not include VM size discovery, SQL image discovery, or cost estimate commands yet.

Current config fields:

```yaml
vm:
  size: "Standard_DS13_V2"
  image:
    publisherName: "MicrosoftSQLServer"
    offer: "sql2022-ws2022"
    skus: "sqldev-gen2"
    version: "latest"
```

Before deploying, verify availability and pricing in the Azure portal, Azure pricing calculator, or Azure PowerShell.

## Roadmap

Future module commands may list VM sizes, list SQL images, and export local cost estimates.
