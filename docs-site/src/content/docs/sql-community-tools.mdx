The sample guest setup installs `dbatools` because the restore helper uses it.

Optional installers for Brent Ozar's First Responder Kit and Ola Hallengren's SQL Server Maintenance Solution are not implemented in the tracked script yet.

## Current Manual Path

After deployment, connect through Bastion and install additional SQL tools manually according to each upstream project's instructions and license terms.

## Roadmap

Future support should keep these installers opt-in, reviewed, version-aware, and documented with clear licensing and operational warnings.
